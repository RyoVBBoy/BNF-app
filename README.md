# BNF PREMIUM (Python版)

BNF流逆張りロジックの分析・シミュレーションツール。

## デザイン刷新(オンボーディング・Material Symbolsアイコン)

- **初回起動時のオンボーディング画面**を追加(アプリ紹介 → 通知許可 → AI設定 → 「はじめる」)。
  一度完了すると次回以降は表示されません(サイドバーの「⟲ 初回設定をやり直す」でリセット可)。
- 絵文字アイコンをやめて **Material Symbols**(線画アイコン)に統一し、Google Fonts「Inter」で
  タイポグラフィを整えました。
- 「AI相場観レポート」「ログ」をカード/フィード形式に刷新し、単なる表や破線ボックスから
  見た目のメリハリがある表示に変更しました。
- 下部ナビ(タブ)はJavaScriptで一番外側のタブバーだけを検出して固定表示する方式のため、
  Streamlitのバージョンが変わっても崩れにくくなっています。

**正直な補足**: StreamlitはX/Instagramのようなネイティブアプリ専用のフレームワークではないため、
完全に同一の操作感(独自アニメーション、ジェスチャーなど)にはなりません。今回はCSS/JSで
再現できる範囲を最大限使って、見た目の質感を近づけています。

## 今回のアップデート内容

1. **全銘柄スキャンの対象拡大(約3,900社)**
   JPX公式の「東証上場銘柄一覧」を毎回ダウンロードして全銘柄を対象にできるようにしました。
   ただし3,900銘柄を毎回1件ずつ取得すると数十分かかる(Yahoo Finance側の制限にも
   かかりやすい)ため、以下の2段階構成にしています。
   - **① 銘柄マスタ更新**: JPXから証券コード・銘柄名・業種を取得(数秒、月1回で十分)
   - **② 価格キャッシュ更新**: 全銘柄の株価・25日線・ATRをバッチ取得してローカルに保存
     (150銘柄ずつまとめて取得。全銘柄で数分かかります。市場が動いた後に1日1回更新する運用を想定)
   - スキャン自体はキャッシュを読むだけなので瞬時に終わります。

2. **UI刷新**
   元のHTML版に近いダーク×紫のデザイン(スコア表示、マーケットバー、BNFコメント欄、
   ピル型ボタンなど)をCSSで再現しました。スマホ・PCどちらでも崩れないようレスポンシブ対応しています。

3. **通知**
   - ブラウザ通知(アプリを開いている間): 元のHTML版と同じWeb Notification API
   - Discord Webhook / ntfy.sh(アプリを閉じていても届く): サイドバーにURL/トピック名を
     入力すると、スキャン完了時に結果を自動送信します(どちらも無料・登録不要)

## セットアップ

```bash
python -m venv venv

pip install -r requirements.txt
streamlit run app.py
```

## 全銘柄スキャンの使い方

1. 「全株スキャン」タブで **① 銘柄マスタ更新** を1回実行(月1回で十分)
2. **② 価格キャッシュ更新** を実行(数分かかります。市場が閉まった後がおすすめ)
3. 以降は **③ スキャン実行** ボタンで瞬時に結果が出ます
4. Discord/ntfyを設定していれば、アプリを閉じていても結果が通知されます

## 通知の設定方法

**Discord**: サーバー設定 → 連携サービス → ウェブフック → 新規作成 → URLをコピーしてサイドバーに貼り付け

**ntfy.sh**: 好きな英数字のトピック名を決めてサイドバーに入力するだけ。
スマホに [ntfy](https://ntfy.sh/) アプリを入れて同じトピック名を購読すると通知が届きます。

## 注意点

- 「② 価格キャッシュ更新」は無料のYahoo Finance経由のため、あまり頻繁に実行すると
  一時的に取得制限がかかることがあります。1日1回程度を推奨します。
- スキャン対象はJPXが公式に公開する「プライム・スタンダード・グロース」市場の
  普通株式のみです(ETF・REIT等は自動的に除外されます)。
